# termsprawl

A spatial terminal manager for Linux: real terminals, editors, and agent
sessions live as draggable nodes on one infinite pan/zoom canvas — everything
sprawls, nothing hides in tabs.

This is an **independent, clean-room implementation** (MIT licensed). It shares
no code with any other terminal-manager project; it is inspired by the general
concept of canvas-based terminals and implements that concept from scratch.

Status: planning → Phase 1 (scaffold).
